LedgerForge Desktop — QUICKSTART
================================

WHAT THIS IS
  LedgerForge as a single Windows application. Double-click LedgerForge.exe:
  it starts its own embedded PostgreSQL and the web UI on your machine
  (127.0.0.1, loopback only — nothing is exposed to the network), then opens
  your browser. Keep the console window open while you work; close it (or
  press Ctrl+C in it) to stop. Your books live in %LOCALAPPDATA%\LedgerForge.

FIRST RUN
  1. Double-click LedgerForge.exe.
     Windows SmartScreen may warn about unsigned binaries — "More info" ->
     "Run anyway". The zip's SHA-256 is published as checksums.txt in the
     release for verification.
  2. Wait for "serving on http://127.0.0.1:8420/" — the first run prepares
     the database; later starts are faster.
  3. Your browser opens on the keyboard-first voucher screen. Post your
     first voucher: type a ledger name, Enter, an amount, Enter ... Ctrl+A
     accepts. Alt+C creates a missing ledger mid-flight, Ctrl+K shows every
     keybinding.

COMMANDS
  LedgerForge.exe                      normal start (port 8420)
  LedgerForge.exe --port 9000          choose the port
  LedgerForge.exe --no-browser         serve without opening a browser
  LedgerForge.exe --data-dir D:\Books  keep the data somewhere else
  LedgerForge.exe --smoke              self-check; exit code 0 = healthy

DATA, BACKUPS, MOVING MACHINES
  Everything lives in the data directory (default %LOCALAPPDATA%\LedgerForge):
  pgdata\ is the embedded database, plugins\ is where signed community
  plugins drop in. Copy the whole folder to move machines; copy it somewhere
  safe for a backup. The engine underneath is append-only and exact-decimal
  double-entry bookkeeping — see the documentation linked below.
