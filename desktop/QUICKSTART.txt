LedgerForge Native — QUICKSTART
===============================

WHAT THIS IS
  LedgerForge as a real desktop program. Double-click LedgerForge.exe: a
  native window opens — its own menus, its own tables, its own file
  dialogs. No browser, no website, no console window. Behind the window an
  embedded engine (PostgreSQL + the LedgerForge core) runs invisibly on
  your machine, loopback only — nothing is exposed to the network. Close
  the window to stop. Your books live in %LOCALAPPDATA%\LedgerForge.

FIRST RUN
  1. Double-click LedgerForge.exe.
     If the binary is unsigned in this release, Windows SmartScreen may
     warn — "More info" -> "Run anyway". The zip's SHA-256 is published as
     checksums.txt in the release for verification, and every update the
     app installs is verified against the release key pinned inside the
     app (Ed25519; its fingerprint is in Help > About LedgerForge).
  2. A small splash says "Starting the embedded engine…". The first run
     prepares the database (about a minute); later starts are faster.
  3. The main window opens on the Day Book. Post your first voucher:
     Ctrl+N, pick a type (JV, PYT, RCT, SAL…), type a ledger name (the
     box autocompletes), an amount, Debit; add the Credit line; when the
     balance label turns green, press "Post voucher". Cost centres…
     (Ctrl+K) splits any line across centres — the remainder is always
     visible; a line is fully allocated or left unallocated. Enter opens
     the selected voucher from the day book; F5 refreshes; Alt+1..6 jump
     between pages; Ctrl+Q quits.

UPDATES (they verify themselves)
  On each start the app fetches the release's signed update manifest and
  checks it against the pinned release key — a manifest that does not
  verify is ignored, always. A newer release downloads quietly (a
  file-level delta where possible — only changed files move), is checked
  byte-for-byte against the manifest, and applies itself the NEXT time
  you start the app, never while you work. The status bar says so, and
  Help > Check for Updates… (Ctrl+U) re-runs the check on demand. Set
  LF_UPDATE_CHECKS=0 in the environment to disable automatic checks, or
  LF_UPDATE_URL to fetch from your own mirror.

CRASH REPORTS (they stay yours)
  If anything crashes, a plain-JSON report lands in
  %LOCALAPPDATA%\LedgerForge\crashes — readable, yours, kept. Nothing is
  ever sent anywhere unless you send it: Help > Crash reports… shows
  what exists and (only if your administrator configured a collector)
  offers a Send button. The reports carry version, platform and the
  traceback — never your books.

THE PAGES
  Day Book        your vouchers: date/type filters, search, double-click to
                  view (Save as PDF is in the voucher window)
  Masters         the chart of accounts: ledgers and groups, New Ledger…,
                  plus the cost trees — Cost Centres and Cost Categories
  Orders          quotations, sales orders, delivery notes, purchase
                  orders, goods receipt notes — each on its own numbering
                  series, each printing as its commercial document;
                  Pending Orders opens the sales/purchase position report
  Banking         statements, the reconciliation proof, the cheque register
  Inventory       stock items, positions by godown, batches/serials,
                  price lists, BOMs and manufacturing
  GST             GSTR-1/3B/9, the 2A/2B ITC reconciliation, e-way bills
  Payroll         runs, payslips, attendance, loans
  Data Exchange   CSV/Excel imports with preview, the TallyPrime XML
                  migration with its verification report, exports
  Reports         Trial Balance, Profit & Loss, Balance Sheet, FY-close
                  preview, GSTR-1 pack, bills receivable/payable with
                  ageing, the party ledger statement, interest on overdue
                  bills, pending orders, cost-centre break-ups
  Periods         financial years: lock, unlock, close preview, close
  Sandbox         plugin dashboards registered by installed plugins

COMMANDS
  LedgerForge.exe                      normal start
  LedgerForge.exe --data-dir D:\Books  keep the data somewhere else
  LedgerForge.exe --smoke              headless self-check; exit code 0
                                       = healthy (what the release runs)

DATA, BACKUPS, MOVING MACHINES
  Everything lives in the data directory (default %LOCALAPPDATA%\LedgerForge):
  pgdata\ is the embedded database, plugins\ is where signed community
  plugins drop in, crashes\ holds crash reports, engine.log is the engine
  child's log. Copy the whole folder to move machines; copy it somewhere
  safe for a backup. The engine underneath is append-only and
  exact-decimal double-entry bookkeeping — see the documentation linked
  below.

OTHER PLATFORMS
  The same native application ships as LedgerForge-<version>-macos-arm64.zip
  (double-click the .app inside) and LedgerForge-<version>-linux-x64.tar.gz
  (extract, run LedgerForge/LedgerForge; a .desktop file rides along), from
  the same releases page.
